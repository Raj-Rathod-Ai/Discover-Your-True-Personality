## 📖 About

**PersonaIQ** is an AI-powered personality prediction application that analyzes **26 behavioral traits** to classify users into one of three personality types:

- 🔮 Introvert
- ⚡ Ambivert
- 🌟 Extrovert

The application uses a trained **Machine Learning model** to generate real-time predictions, confidence scores, and probability analysis through a modern, responsive Streamlit interface.
